# Scratch 積木群島

網站：https://ldjh-scratch-islands.vercel.app

十座虛擬島嶼，依資訊課的學習順序認識 Scratch 九大積木類別：事件、動作、外觀、音效、迴圈、偵測、運算、變數與列表、判斷、函式積木。

- 3D 群島地圖（Three.js），直升機從停機坪來接送，到目的島上空跳傘降落
- 每座島：觀念、積木、範例程式、Python／JavaScript 對照、常見錯誤、島長任務
- 每座島有進度百分比，未完成離島會跳出警示
- RPG：建立角色（四種職業）、等級與經驗值、金幣、體力、島長對話、島嶼徽章、背包與商店
- 日夜變化：3D 島嶼的天色、海色、光線依真實時間變化，可一鍵快轉一天
- 進度與角色存在瀏覽器的 localStorage

純靜態網頁，只有一個 `index.html`，直接用瀏覽器開就能跑。
